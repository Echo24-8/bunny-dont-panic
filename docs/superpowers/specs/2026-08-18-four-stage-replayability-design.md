# 《兔兔别慌》四关重玩性升级设计

## 目标

把当前两关、固定流程的浏览器小游戏升级为三到四关的小型闯关游戏，解决“玩过一次后缺少继续游玩动力”的问题，同时保留《兔兔别慌》的核心身份：手账贴纸森林、自动武器攻击、玩家移动躲避弹幕、原生 Canvas 2D、浏览器即开即玩。

本版本增加三类重复游玩动力：

- 局内事件、敌人组合和构筑变化；
- 一个可主动释放的技能；
- 轻量的本地解锁、图鉴和挑战目标。

## 已确认决策

- 采用四关线性流程，不做地图节点式大地图。
- 一局目标时长约 4～5 分钟。
- 武器继续自动瞄准和释放，玩家主要负责移动和躲避。
- 每局只装备一个主动技能，使用一个技能按钮。
- 每关结束从两张随机事件卡中选择一张。
- 第三关加入精英敌人，第四关加入两阶段 Boss。
- 事件随机使用固定种子，保证同一局可以复盘和测试。
- 局外进度保存在浏览器本地，但只解锁选择、图鉴和装饰，不提供大幅永久属性膨胀。
- 不增加账号、云存档、联网排行榜、广告、付费和微信小游戏入口。

## 核心循环

一局游戏遵循：

```text
移动躲避 → 自动攻击 → 击败敌人 → 拾取经验 → 选择升级
        → 触发主动技能 → 通过关卡 → 选择随机事件
        → 进入下一关或挑战 Boss → 结算挑战和解锁
```

每个 30 秒循环都必须包含明确的行动、反馈和奖励。升级、事件和主动技能不能只是文本变化，必须改变下一段战斗中的路线、风险或输出窗口。

## 关卡结构

### 第一关：森林入口

- 时长：45 秒。
- 保留现有教学敌人和经验引导。
- 让玩家完成移动、自动攻击、拾取经验和第一次升级。
- 敌人密度低，主动技能可以在结尾前获得一次教学机会。

### 第二关：暴雨弹幕

- 时长：60 秒。
- 保留现有高密度弹幕和固定阶段时间轴。
- 增加更多阶段方向提示和安全路线轮廓。
- 当前第二关的准备期、阶段预告和固定弹幕规则继续保留。

### 第三关：精英区域

- 时长：75 秒。
- 加入精英敌人和风险奖励事件。
- 精英敌人一次只使用一种词缀：迅捷、护甲、分裂或召唤。
- 同屏最多出现一个带词缀的精英主体，避免规则叠加导致不可读。
- 玩家可以选择保持安全路线，或主动接近精英以获得更高奖励。

### 第四关：森林守护者

- 时长：75～90 秒。
- Boss 分为两个阶段。
- 第一阶段使用追踪、扇形和环形攻击，给玩家学习节奏的时间。
- 第二阶段增加范围攻击或移动限制，但必须提前显示危险方向和发射源。
- Boss 攻击采用固定阶段顺序加少量种子变化，不使用完全随机的不可复盘攻击。

## 随机事件

每关结束展示两张事件卡，玩家选择一张后进入下一关。事件只影响当前局，不直接修改长期基础属性。

事件类型：

- **补给事件**：恢复一颗心，或获得一次普通升级。
- **强化事件**：强化当前主动技能，或强化当前一把武器。
- **冒险事件**：立即挑战一个精英敌人，成功后获得稀有升级。
- **休整事件**：下一关开场获得短暂护盾。
- **交换事件**：放弃当前一项小增益，获得一次更高质量的升级选择。

事件生成规则：

- 每局开始生成一个有限范围内的随机种子。
- 种子只决定事件顺序、候选内容和少量敌人变体，不改变基础碰撞边界。
- 事件候选必须经过过滤，不能出现两个效果完全相同的选项。
- 没有可用奖励时回退到安全补给事件，保证流程不会卡住。

## 主动技能

每局只装备一个主动技能。技能拥有独立冷却时间，自动武器不受主动技能输入影响。

初始技能和解锁技能：

- **兔兔冲刺**：向移动方向快速冲刺，短时间无敌。
- **棉花护体**：生成短暂护盾，抵挡一定数量的敌弹。
- **森林回响**：对屏幕内敌人造成一次范围伤害，并短暂清理附近敌弹。

技能规则：

- 第一局默认提供兔兔冲刺。
- 其余技能通过通关或挑战解锁。
- 同一局不能同时装备多个主动技能。
- 技能按钮始终显示可用状态或剩余冷却时间。
- 键盘使用一个独立按键，触屏使用战斗画面下方的独立技能按钮。
- 技能触发必须产生清晰但短暂的视觉反馈；启用减少动态效果时保留静态高对比反馈。

技能升级只改变一项主要参数，例如冲刺距离、护盾持续时间或范围伤害冷却，不同时叠加多个隐藏公式。

## 武器和构筑

现有五把自动武器和三槽结构继续保留。升级候选需要尽量覆盖不同类别，避免三张卡都指向同一类收益。

保留并扩展轻量协同：

- 移速与星星回旋镖：移速等级提高回旋镖回收速度。
- 护盾与蜂蜜泡泡：护盾等级提高泡泡环绕覆盖半径。

后续协同必须满足：

- 有可读的卡片提示；
- 只改变一个明确的统计量；
- 有核心层单元测试；
- 不把基础武器变成必须绑定某个辅助能力才能使用。

## 局外进度

新增版本化的本地进度键，例如 `bunny-dont-panic-progress-v1`。存储内容包括：

- 已解锁的主动技能；
- 已见过的敌人和 Boss 图鉴；
- 已完成的挑战 ID；
- 已解锁的贴纸、背景或角色装饰；
- 最近完成的最高关卡。

不保存：

- 正在进行的战斗；
- 账号信息；
- 云端数据；
- 可无限叠加的基础攻击或生命加成。

当 `localStorage` 不可用、数据损坏或版本不匹配时，回退到默认解锁状态，游戏仍然可以启动和完成一局。

## 挑战和图鉴

结果页和菜单提供轻量挑战目标：

- 不损失生命完成第二关；
- 只携带两把武器通关；
- 使用主动技能达到指定次数；
- 在限定时间内击败 Boss；
- 不选择恢复类升级完成一局。

挑战奖励以技能解锁、图鉴记录和装饰内容为主，避免玩家必须长时间刷取永久数值才能正常体验新内容。

## 模块边界

### 核心模块

- `src/core/campaign.js`：关卡定义、阶段切换、事件种子和事件候选。
- `src/core/active-skills.js`：主动技能定义、冷却、触发结果和技能预览。
- `src/core/elites.js`：精英词缀和精英生成规则。
- `src/core/bosses.js`：Boss 阶段和固定攻击规格。
- `src/core/progression.js`：挑战、图鉴和解锁的纯逻辑。
- `src/core/state.js`：挂载当前关卡、事件、主动技能和本局进度，不直接读写浏览器 API。
- `src/core/world.js`：执行生成、移动、碰撞、对象池和核心事件。

### 平台和编排

- `src/platform/browser.js`：增加主动技能动作、触屏按钮和版本化进度存储适配。
- `src/game/create-game.js`：编排阶段切换、事件选择、技能触发、结果和可访问播报。

### 渲染

- `src/render/renderer.js`：绘制事件卡、技能按钮、Boss 阶段提示、挑战进度和图鉴入口。
- Canvas 继续使用 360×640 逻辑坐标；所有新增按钮命中区域至少 44×44。

## 数据流

```text
platform.input
  → create-game 编排动作
  → core state / campaign / active-skills
  → world 固定步更新
  → events 返回编排层
  → renderer 绘制当前阶段和反馈
  → platform.storage 保存解锁与挑战结果
```

核心逻辑不能访问 DOM、`navigator`、`localStorage` 或 Canvas。平台能力通过适配器注入，便于 Node 测试和未来移植。

## 性能和稳定性约束

- 继续使用固定步长逻辑和尽可能快的渲染。
- 子弹、敌人、粒子、精英特效和 Boss 特效必须使用对象池。
- 不在每帧热循环中创建临时对象或闭包集合。
- 保持敌弹池上限 450、玩家弹池上限 128 和现有粒子池预算，除非压力测试给出明确理由。
- Boss 阶段最多新增少量预告图形，不用复杂滤镜或 `shadowBlur`。
- 页面隐藏、失焦和音频暂停继续沿用现有浏览器生命周期适配。

## 测试和验收

### 核心单元测试

- 四关时长、阶段切换和结果状态正确；
- 事件种子在相同输入下产生相同候选；
- 事件候选不存在重复或无效奖励；
- 主动技能冷却、触发和无敌/清弹边界正确；
- 精英词缀互斥且生成上限正确；
- Boss 阶段只各触发一次并提供预告；
- 局外解锁只增不减，损坏存储可以回退；
- 挑战判定不受刷新或重复结算影响。

### 浏览器验收

- 360×640、390×844 和 1280×800 下事件卡、技能按钮、Boss 预告和 HUD 不重叠；
- 键盘和触屏都能稳定触发主动技能；
- 完整四关流程可以开始、暂停、失败、重试和通关；
- 同一种子重试时事件和 Boss 主攻击顺序一致；
- 高密度弹幕和 Boss 阶段下画面保持可读，主流 Chromium 预热后目标不低于 55 FPS；
- 刷新后技能解锁、图鉴和挑战进度仍然存在；
- 清除或损坏本地进度不会阻止游戏启动。

## 实施顺序

1. campaign 状态、四关转场和事件卡框架；
2. 主动技能动作、按钮和冷却；
3. 精英敌人和第三关内容；
4. Boss 和第四关内容；
5. 局外解锁、挑战和图鉴；
6. 浏览器验收、平衡调试和性能压力测试。

每个阶段独立通过纯逻辑测试后再进入下一阶段。大版本不在第一步引入 PWA、联网排行榜、第三方引擎或后端服务。

## 非目标

- 不改为 Phaser、PixiJS、WebGPU 或其他运行时；
- 不增加多人联机、账号、云存档、广告或付费系统；
- 不把玩家操作改成手动瞄准为主；
- 不用永久数值膨胀掩盖关卡内容不足；
- 不在同一版本加入超过一个主动技能槽或复杂商店经济。
