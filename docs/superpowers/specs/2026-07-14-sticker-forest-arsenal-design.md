# 《兔兔别慌》手账贴纸森林与多武器改造设计

## 目标

在不改变两关时长、第二关弹幕路线、三颗心、升级暂停和跟随摇杆的前提下，完成两项改造：

1. 将角色、敌人、背景、HUD、按钮和升级卡统一为“手账贴纸森林”。
2. 将单一胡萝卜弹升级为 5 把全自动武器、3 个装备槽和武器/辅助能力混合三选一。

## 已确认决策

- 视觉方向：B「手账贴纸森林」。
- 所有武器自动攻击，玩家只负责移动躲弹。
- 5 把武器从第一局开始全部进入随机卡池，不做局外解锁。
- 每局默认装备胡萝卜飞镖，最多携带 3 把武器，每把最高 3 级。
- 武器和辅助能力共用升级三选一。
- 散射、穿透不再作为全局能力，分别并入蒲公英和回旋镖。
- 辅助能力保留全局射速、移动速度、棉花护盾和幸运红心。
- 第二关失败后恢复三颗心、清空经验进度和场上实体，但保留武器、武器等级、辅助能力和升级次数。

## 视觉系统

### 视觉签名

画面像一本正在被弹幕打乱的儿童手账：方格纸纹理、白色模切贴纸边、蜡笔描线、胶带云朵和剪纸草坡。最鲜明的识别点是“武器贴纸槽”，三枚武器贴纸固定出现在 HUD 下方，等级用小铅笔刻痕表达。

### 色彩

- 纸张白：`#fffaf0`
- 墨水深绿：`#29474c`
- 薄荷绿：`#79c99e`
- 珊瑚红：`#ef6262`
- 柠檬黄：`#f4d45f`
- 天空蓝：`#83bfd1`
- 栗子棕：`#9a6648`
- 暴雨蓝灰：`#668b93`

不采用通用数据库建议的粉紫主色，避免与已确认的森林手账方向冲突。敌弹继续使用珊瑚红加纸白描边，背景不得出现相似红色圆点。

### 字体与形状

- 中文使用系统圆体回退：`Microsoft YaHei UI`, `PingFang SC`, sans-serif。
- 倒计时使用等宽数字，避免数字跳动。
- 面板最大圆角 8px；使用略不对称的纸张轮廓、双层硬阴影和胶带角标表达手作感。
- 点击区域至少 44×44 逻辑像素，按钮按压只改变阴影和 1px 位移，不改变布局尺寸。

### 素材

保留 6 个 manifest ID，使用新文件名避免旧缓存：

- `bunny-sticker.png`：大头短身白兔、腮红、薄荷围巾、白色模切边。
- `enemy-cloud-bear.png`：桃粉云朵熊，宽而蓬松。
- `enemy-acorn-mouse.png`：橡果帽小鼠，栗色与天蓝。
- `enemy-star-chick.png`：星星外套小鸡，柠檬黄与靛蓝。
- `notebook-forest-day.png`：明亮方格纸、胶带云、剪纸草坡。
- `notebook-forest-storm.png`：同场景暴雨版本，蓝灰天空与暖黄纸片。

角色素材严格居中、透明背景、无地面阴影；背景为 1080×1920，顶部 HUD 区域低细节。武器图标不增加图片资源，统一使用 Canvas 绘制。

## 武器系统

### 构筑结构

```js
{
  rapidFire: 0,
  moveSpeed: 0,
  shield: 0,
  weaponSlots: [
    { id: 'carrot', level: 1 },
    null,
    null
  ]
}
```

构筑复制必须深拷贝 `weaponSlots`。新局回到默认胡萝卜一级；第一关进入第二关原样保留；第二关重试深度保留。

### 五把武器

| 武器 | 定位 | 1/2/3 级变化 | 视觉 |
|---|---|---|---|
| 胡萝卜飞镖 | 最近敌人、稳定单体 | 提高伤害并在 3 级双发 | 橙色胡萝卜贴纸弹 |
| 蒲公英散射 | 扇形范围覆盖 | 3/5/7 枚种子 | 乳白种子与柠檬芯 |
| 星星回旋镖 | 往返穿透 | 提高穿透、伤害和回收速度 | 黄星配靛蓝描边 |
| 蜂蜜泡泡 | 环绕攻击兼拦截 | 1/2/3 枚环绕泡泡 | 琥珀泡泡配天蓝高光 |
| 云朵闪电 | 低频连锁打击 | 2/3/4 个不同敌人 | 浅蓝云和柠檬闪电 |

所有武器冷却乘以全局射速倍率，彼此独立。没有敌人时，胡萝卜、蒲公英和回旋镖继续向上释放，保持现有教学反馈。

### 升级池

- 已拥有且未满 3 级的武器可升级。
- 未拥有武器仅在有空槽时可出现，选择后填入第一个空槽并成为 1 级。
- 3 槽已满后排除未拥有武器。
- 满级武器、满级辅助能力和满血红心均排除。
- 候选卡 ID 唯一。
- 玩家只有默认胡萝卜时，第一次升级保证至少出现 1 张新武器卡，尽早展示武器库价值。

### 对象池与碰撞

- 敌弹池继续上限 450，弹幕规则不变。
- 玩家普通弹池继续上限 128，耗尽时跳过并记录 `droppedPlayerBullets`。
- 新增最多 3 个泡泡环绕物和最多 24 个短暂武器特效。
- 普通弹统一初始化所有武器字段，防止对象池复用时继承旧行为。
- 碰撞顺序：玩家弹命中敌人；泡泡拦截敌人/敌弹；剩余敌弹/敌人命中玩家。
- 回旋镖记录本轮已命中的敌人，避免同一重叠目标连续帧重复受伤。
- 闪电释放时直接结算不同敌人，并把轨迹写入短暂特效池。

## 界面

- HUD 顶部保留三颗心、倒计时、设置按钮和经验条。
- 经验条下方增加 3 个 40px 武器贴纸槽；空槽使用虚线轮廓，已装备显示图标和 `Lv`。
- 升级卡增加类别标签：`新武器`、`武器升级`、`辅助能力`、`立即生效`。
- 武器卡使用对应颜色和专用 Canvas 图标；辅助能力继续使用护盾、鞋、发条和红心图标。
- 结果页与分享图优先列出三把武器，再显示辅助能力摘要。
- 角色敌人不再整圈旋转，改为轻微左右摇摆，保证动物脸始终可读。

## 验收标准

- 5 把武器全部可从第一局卡池出现，最多装备 3 把，各自可升到 3 级。
- 第一关、第二关、失败重试和通关流程不回退。
- 第二关重试深度保留武器与辅助能力，不保留当前经验。
- 450 敌弹压力下对象池不越界，玩家武器池耗尽时安全降级。
- 360×640、390×844、1280×800 下 HUD、武器槽、文字和摇杆不重叠。
- 所有按钮命中区域至少 44×44；键盘数字 1/2/3 可选升级卡。
- `node --test` 全部通过，浏览器控制和本地开发服务器可正常运行。

## 非目标

- 不增加 Boss、第三关、手动瞄准、局外货币、武器解锁、账号存档或微信入口。
- 不改第二关固定弹幕路线和 60 秒极难目标。
- 不增加第三方框架、游戏引擎或运行时依赖。
