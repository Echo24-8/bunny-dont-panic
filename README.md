# 兔兔别慌

一个手账贴纸森林风格的原生 Canvas 2D 浏览器小游戏：四关线性生存流程（45/60/75/90 秒），每关结束从两张随机事件卡中选择路线，第三关会出现带词缀的精英敌人，第四关迎战两阶段森林守护者。

## 运行

```powershell
npm test
npm run dev -- --host 0.0.0.0 --port 4173
```

桌面浏览器打开 `http://localhost:4173`。同一局域网内的手机可以使用终端输出的 `Network` 地址。

电脑使用方向键或 WASD 移动，数字键 1–3 选择升级，Space 释放主动技能；手机触摸战斗画面下半部分即可生成浮动摇杆，右下角按钮释放技能。武器会全部自动瞄准和释放，玩家主要通过移动、技能和路线选择应对弹幕。

每局装备一个主动技能：兔兔冲刺、棉花护体或森林回响。主动技能拥有独立冷却，事件卡可以提供治疗、临时护盾、技能冷却强化或额外经验。

## 武器库

每局默认携带胡萝卜飞镖，升级时会将武器和辅助能力混合成三选一。五把武器从第一局起全部开放，每局最多携带三把，每把最高三级：

- 胡萝卜飞镖：稳定追踪最近敌人。
- 蒲公英散射：发射 3/5/7 枚扇形种子。
- 星星回旋镖：飞出后返回并连续穿透。
- 蜂蜜泡泡：环绕兔兔，攻击敌人并拦截敌弹。
- 云朵闪电：低频连锁打击多个不同敌人。

失败重试会恢复三颗心并清空当前经验，但保留已有武器、武器等级和辅助能力。通关后会在浏览器本地保存已见敌人、最高关卡、技能解锁和挑战完成状态；存储损坏或不可用时自动回退默认进度。

## 素材

项目不依赖第三方运行库或外部素材。手账贴纸 PNG 和原创合成音频可通过以下命令重新生成：

```powershell
npm run generate:art
npm run generate:audio
```

`generate:audio` 使用本机 `ffmpeg` 将原创 PCM 配乐编码为 MP3。

## 分享战绩

结果页可以调用系统分享；不支持系统分享时会复制真实战绩文字并保存 1080×1440 PNG 战绩图。为避免好友收到无法访问的地址，`localhost`、局域网和其他私有地址不会写入分享内容。通过微信发送可直接游玩的链接仍需后续部署到公网 HTTPS 地址。

## 结构

- `src/core/`：状态、对象池、升级、弹幕与世界模拟。
- `src/platform/`：浏览器输入、音频、存储和生命周期适配。
- `src/render/`：Canvas 场景与界面绘制。
- `assets/`：游戏实际加载的 PNG、MP3 和 WAV。
- `tests/`：Node 内置测试运行的纯逻辑用例。

当前版本不包含微信小游戏入口、广告、排行榜、账号或云存档。
